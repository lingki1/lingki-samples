# Lingki · AI 实战示例

这里放的是 Lingki 的「AI 实战示例」系列视频里做出来的东西。

这个系列每一期是一堂照着做的课：找一件普通人真会碰上的麻烦事，用大白话跟 AI 说几句，一步一步把它做成能用的小工具。课上做出来的工具、每一步的版本、用来练手的样例、整段对话的记录，都放在这里，给你看、下载、照着做、接着改。

## 目录

| 课 | 做了什么 | 文件夹 |
|---|---|---|
| 第一课 | 不会编程，照着做，用 AI 做出你的第一个小软件。例子是发票整理助手：批量改名、自动分类、标记重复、导出表格 | [AI实战示例 - 第一期 发票整理助手](AI实战示例%20-%20第一期%20发票整理助手/) |
| 第二课 | 不会编程，也照软件公司的正规流程来：先出文档再动手、改需求先改文档、交付前开代码审查、最后问它动过电脑上什么。例子是作业排版：把一个班格式五花八门的 Word 作业一次改成学校要求的格式 | [AI实战教程 - 第二期 作业排版](AI实战教程%20-%20第二期%20作业排版/) |

## 怎么下载

- 只要某一个文件：点进去，再点右上角的下载按钮（Download raw file）。
- 要整个仓库：点本页绿色的 **Code → Download ZIP**，下载后解压。
