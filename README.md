# Lingki · AI 实战示例

这里放的是 Lingki 的「AI 实战示例」系列视频里做出来的东西。

这个系列的做法是：用大白话跟 AI 说几句，让它把一件具体的麻烦事做成能用的小工具。视频里做出来的工具、每一步的版本、用来试的样例、整段对话的记录，都放在这里，给你看、下载、照着学、接着改。

## 目录

| 期 | 做了什么 | 文件夹 |
|---|---|---|
| 第一期 | 五句话，做出一个发票整理软件：批量改名、自动分类、标记重复、导出表格 | [AI实战示例 - 第一期 发票整理助手](AI实战示例%20-%20第一期%20发票整理助手/) |

## 怎么下载

- 只要某一个文件：点进去，再点右上角的下载按钮（Download raw file）。
- 要整个仓库：点本页绿色的 **Code → Download ZIP**，下载后解压。

## 用之前

- 这些是视频里的演示成品，**不是打磨过的正式软件**。每一期的 README 里都写了它核对到什么程度、有哪些已知的毛病，请先看。
- 示例里出现的发票、公司、人名、数字，除非特别注明，都是为了演示编的。
- 每一期各自带着许可文件（`LICENSE`）和第三方组件的说明。
