# 样例说明

这个文件夹里的作业、名单、格式要求，**全部是我们自己造的**：用程序生成，学生的姓名、学号、班级（高二（3）班）、学校（青岚中学）、作业内容都是编的。如果和真实的人或学校重名，纯属巧合。

## 有什么

| 名字 | 是什么 | 什么时候进的那场对话 |
|---|---|---|
| `学生作业/` | 38 个文件：34 个 .docx、2 个旧格式的 .doc、1 个 PDF、1 个仿 Word 没关时留下的临时文件（`~$林知夏.docx`） | 开场就在 |
| `格式要求.docx` | 学校的八条格式要求 | 开场就在 |
| `名单.xlsx` | 班级名单，36 人，两列：学号、姓名 | 第二句时放进去的 |
| `老师的决定.xlsx` | 两条决定：匿名那份是童年的；梁思齐以文件名带 (1) 的那份为准。第二页是「怎么填」 | 不是我们给的，是第三句之后它自己建的 |
| `make_samples.py` | 造 `学生作业/` 和 `格式要求.docx` 的脚本 | 没给它看 |
| `truth.json` | 标准答案：每个文件是谁的、埋了什么坑、每一段是题目还是正文、原文是什么、文件指纹 | 没给它看 |

`名单.xlsx` 不是这个脚本生成的，是另外造的，名字和学号同脚本里的一致。

**跟着课做一遍**：新文件夹里只放 `学生作业/` 和 `格式要求.docx`，第二句时再放 `名单.xlsx`。脚本和标准答案不要放进去。

**直接用做好的软件**：把 `学生作业/`、`格式要求.docx`、`名单.xlsx`、`老师的决定.xlsx` 四样复制到上一级的 `成品/` 里。

## 埋了哪些坑

36 个学生，每人一份，六个题目轮着写；字体、字号、行距、对齐、缩进的做法、小标题的写法、文件名的习惯都是按固定的种子随机配的。另外按学号指定了这些坑（那场对话事先不知道）：

| 坑 | 哪几份（学号末两位、姓名） |
|---|---|
| 旧格式 .doc | 07 唐小满、27 邱实 |
| 交成了 PDF | 32 齐悦 |
| Word 没关留下的临时文件 `~$林知夏.docx` | 不是作业 |
| 同一个人交了两次（第二份改了一个数） | 24 梁思齐 |
| 姓名学号只写在页眉里 | 02 周子衿、16 陆景明 |
| 文档里没写姓名学号，只有文件名里有名字 | 13 叶知秋 |
| 哪儿都没写（文件名是「新建 Microsoft Word 文档」） | 21 童年 |
| 文件名看不出是谁，文档里有 | 19 秦朗（`report_qinlang`）、29 殷实（`新建 Microsoft Word 文档 (2)`）、35 池鱼（`文档1`） |
| 交了空白文档 | 33 尚可 |
| 没写题目 | 25 安然 |
| 有表格 / 有图片 | 03 陈一诺 / 08 白鹿鸣 |
| 段落之间空行 | 05 沈星河、14 方可、27 邱实 |
| 一节只有一个段落，用换行（Shift+回车）隔开 | 11 夏以宁 |
| 横向纸 | 17 温言 |
| 自己加粗加黄底标了一句重点 | 09 江晚晴、30 骆一鸣 |
| 字体设在样式上、字本身没设 | 06 顾念、19 秦朗 |
| 小标题没编号也没加粗 | 04 许嘉树 |
| 首行缩进是敲空格、全角空格、Tab 敲出来的 | 十几份 |

小标题的编号四种写法都有：「一、」「1.」「（一）」和不编号。

## 这批样例和真作业不一样的地方

用之前要知道，这些地方决定了「在样例上全对」说明不了多少：

- **它们是程序生成的，不是微软 Word 保存出来的。** 那场对话在代码审查时自己指出来了：真实的 Word 文件里很常见的一些内部结构（Word 存盘时留的记号、公式、插入的符号、图表、自动编号、超链接），在这 38 个文件里一个都没出现。文件的作者信息里写的也是生成它们的那个库的名字。
- **34 份 .docx 全不是 A4 纸。** 造的时候没料到：生成文件用的库，默认模板是 Letter 纸。原本只想让 22 乔木一份不是。那场对话在第一轮就看出来了。
- **内容只有六个题目**，每个题目三节、每节两段，只是数字因人而异。真作业不会这么整齐。
- **有一处自己不协调**：03 陈一诺写的是图书角，文档里那张表却是排队的分钟数（表格的内容在脚本里是固定的）。不是软件排错了。
- 两份 .doc 和那份 PDF 是用 LibreOffice 从 .docx 转出来的；`~$林知夏.docx` 只是照那类临时文件的样子造的一个 162 字节的小文件，不是 Word 真的留下的。

## 重新生成

```powershell
python make_samples.py
```

需要 python-docx、Pillow，和装在默认位置的 LibreOffice。它会在脚本旁边新建一个 `project-seed/`（里面是 `学生作业/` 和 `格式要求.docx`），并**重写旁边的 `truth.json`**。

种子是固定的，重跑出来的文字和格式设置同这里的一样（我们在整理仓库时试过一次：除了文件指纹，标准答案的内容完全相同）。但文件本身的字节不一样，因为文件里带着生成的时间，所以 `truth.json` 里的指纹会跟着变。要核对课上那次的结果，用这里现成的这批和现成的 `truth.json`，别重新生成。
