# AI 实战示例 · 第一课：不会编程，照着做，用 AI 做出你的第一个小软件

这一课的例子：**发票整理助手**。

视频是一堂照着做的课：教不会编程的人，用 Claude 桌面版里的 Code，一步一步做出自己的第一个小软件。课上的示范是一件真事：85 张名字乱七八糟的电子发票，要改名、分类、找重复、汇成一张表。做示范的人装成完全不懂电脑的样子，从头到尾只说了五句话。

这个文件夹里是这一课的全部东西：做出来的工具、每一轮的版本、用来练手的样例发票、整段对话的记录，还有我们自己核对的结果。你可以下载样例跟着做一遍，也可以拿做好的工具接着往下改。

## 跟着这节课做一遍

这里是课上步骤的文字版，细节看视频。

**先备三样**：一台电脑；Claude 的桌面版（官网下载，装好、登录）；一个付费订阅（Pro、Max、Team 或 Enterprise，没有它点不开 Code）。Claude 只在官方支持的国家和地区开放。

1. **给它一个工位。** 新建一个文件夹，把要处理的东西放进去（想做得和课上一样，就把这里的 `样例发票` 文件夹放进去）。打开 Claude，点 Code，选中这个文件夹；它问信不信任这个文件夹时，自己建的就点信任。输入框下面那个档位选 Manual：它每动一下手，都先问你。
2. **说第一句话。** 公式就三样：我有什么、我要什么、我是谁。课上的第一句见下面「课上的五句话」。
3. **它来问你，看懂了再点。** 先看卡片上那一行说明。看得懂、和你的事有关，点「只允许这一次」（Allow once）；看不懂就点「拒绝」（Deny），再打字问它刚才那一步要干什么。
4. **验收。** 自己用一遍；抽几张和原件对一对；翻到它回复的最后，看它自己交代了哪里没测到；把不对、不顺手的地方记下来。
5. **让它改。** 还在同一个对话里接着说。四种说法：它问你，就说你的实际情况；说不出专业的话，就说你看见的毛病；自己也不知道怎么办，就把选择题交给它；换了地方出问题，就说你在哪儿、看见了什么。每改完一次，回第 4 步再验一遍。

你做出来的不会和课上的一模一样：同样的话，它每次的做法会有出入；你的电脑上装了什么，也会影响它怎么选。这是正常的。

## 这个工具能做什么

`发票整理助手.html` 是一个网页文件，只有这一个文件，不用安装，不用联网。把一堆名字乱七八糟的电子发票（PDF）交给它，它会：

- **批量改名**：改成 `2026-09-16_半山咖啡馆_104.67元.pdf` 这样一眼看得懂的名字
- **自动分类**：按餐饮、交通出行、住宿、办公用品、快递物流、通讯网络分文件夹，也可以按月份分
- **标记重复**：同一张发票存了两份的，单独挑出来，可以并排对比、选留哪一张
- **导出表格**：生成一张「发票汇总表.xlsx」，有每张发票的明细和分类合计

它只在你自己的电脑或手机上处理，发票不会上传到任何地方。我们核对时把网络掐断了，它照常工作，也没有往外发过任何请求。它不会改动、也不会删除你原来的文件，只是把整理好的另存一份。

**用之前请先看下面的「重要说明」。**

## 怎么用

### 在电脑上

1. 点开上面的 `发票整理助手.html`，再点右上角的下载按钮（Download raw file），把它存到电脑上。
2. 双击它，用 **Edge 或 Chrome** 打开（Windows 自带 Edge）。
3. 点蓝色的「选择发票文件夹」，选中装着发票的那个文件夹。浏览器会问是否允许查看和修改文件，点「允许」。
4. 等它读完，看一眼识别结果。读不出来的会排在最上面标红，可以点「查看原件」对照着手动填。
5. 点「开始整理」。它会在你选的文件夹里新建一个「整理好的发票_日期_时间」，改好名、分好类的发票和汇总表都在里面。

不要直接选「桌面」「下载」「文档」这几个文件夹本身，浏览器不让。把发票放进一个单独的文件夹再选。

### 在手机上

1. 把 `发票整理助手.html` 传到手机，**用浏览器打开**。AI 提醒过：在微信或 QQ 里直接点开的是聊天软件自带的预览，很可能用不了（这一点我们没有试）。
2. 手机浏览器大多不能直接整理文件夹，所以页面上的按钮会自动变成「选择发票文件」，一次可以选很多个。
3. 点「整理并打包下载」，会得到一个压缩包，解开就是分好类的文件夹和汇总表。

### 想先试试，手头又没有发票

点这个仓库首页绿色的 **Code → Download ZIP**，把整个仓库下载下来解压。打开工具后选里面的「样例发票」文件夹，那里有 85 个我们造的样例（80 张不重样的发票、3 张重复的、1 张只有图片读不出字的、1 份不是发票的行程单），正好能看到它每一种处理。

## 课上的五句话

下面是做示范的人说的原话，一个字没改。每一句后面是 AI 接着做的事。完整的记录（它说的每一句话、跑的每一条命令）在 [`对话记录/五轮对话.md`](对话记录/五轮对话.md)。

### 第一句

> 你好，我这里有很多发票，我需要你帮我做一个软件对他们进行整理。我需要有 批量改名、自动分类、导出表格、标记重复 这些功能。
> 我不懂电脑和编程

它先看了文件夹（85 个 PDF），查了这台电脑上有什么（找不到 Python，有 Edge 和 Chrome，没有 Excel 和 WPS），直接打开读了 6 个 PDF（包括那张只有图片的和那份行程单），还顺手找出了 3 对内容一模一样的文件。然后它没有让人装任何东西，做了一个双击就能用的网页，用这 85 个文件的副本自己跑了一遍，最后问：要不要让它断网也能用？

用了 14 分钟，动了 47 次工具。成品：[`版本/v1-第一版.html`](版本/v1-第一版.html)

### 第二句

> 可以，下载吧。我想把这个软件发给同事用，他们的电脑不一定能上网，最好还是只发一个文件就行。

它下载了读 PDF 用的开源组件（Mozilla 的 pdf.js）和 27 个简体中文字符对照表，每一个都对过官方的校验码，然后全部塞进了同一个文件里。断开网络，在 Chrome 和 Edge 里各测了一遍。

用了 10 分钟，23 次工具。成品：[`版本/v2-断网也能用.html`](版本/v2-断网也能用.html)

### 第三句

> 网页布局设计有点混乱，不容易一眼看清楚内容。需要进行UI排版的美化。

这句是故意照普通人的口气说的，没讲具体要怎么改。它把界面整个重排了：顶上一排汇总数字，筛选标签，干净的表格，底部固定的操作栏。认发票、改名、分类的逻辑没动。

用了 8 分钟，25 次工具。成品：[`版本/v3-界面改版.html`](版本/v3-界面改版.html)

### 第四句

> 重复发票里， 需要点击查看后对比两张重复发票，并且有额外功能 保存哪一张，重复的另一张如何处理

「另一张如何处理」是故意留给它的，看它能不能自己拿出办法。它做了一个并排对比的窗口，给了三种处理：另一张单独放进「重复发票」文件夹、不放进整理结果、或者「它们不是重复，都保留」。它没有做「删除原文件」，理由是删错了找不回来。

用了 5 分钟，38 次工具。成品：[`版本/v4-重复发票对比.html`](版本/v4-重复发票对比.html)

### 第五句

> 我把这个文件传到了手机，发现排版全乱了。

这句只说了现象，没说「给我做个手机版」。它不光把排版改成了手机能看的样子，还自己指出了更要紧的一件事：手机浏览器大多不能直接整理文件夹。于是加了「选文件、整理完打包下载」这条路，并且提醒了三件事：微信里直接点开可能用不了、苹果手机它确认不了、发票多的时候还是电脑上舒服。

用了 7 分钟，50 次工具。成品：[`版本/v5-手机适配.html`](版本/v5-手机适配.html)，和最外面的 `发票整理助手.html` 是同一个文件。

五轮加起来，它自己干活的时间大约 45 分钟，动了 183 次工具。

## 重要说明

- **样例发票是我们自己造的，不是真发票。** 拿不到可以公开的真发票，所以公司名、号码、金额全是编的（如果和哪家真实的店或公司重名，纯属巧合）。每一页都压着「样例 · 非真实发票」的水印，税号里带着 SAMPLE 字样，没有章和二维码，版式也不是照官方的排的。
- **它认发票的规则，是照着这 85 个样例写出来的。** 所以它在样例上全对并不稀奇。**换成真发票准不准，没有验证过。** 请不要直接拿它处理正式的账；真要用，先拿几张自己的发票试，每一格都对一遍。
- **它只管整理**：改名、分类、汇总、挑重复。它不验发票的真伪；整理好了也不等于符合报销或入账的归档要求，那些另有规定。
- **录制时，我们故意把这台电脑上的 Python 藏了起来。** 那台电脑上其实装着 Python，我们想看的是：在一台什么都没装的电脑上，它会怎么办。它没有让人去装东西，直接做了一个不用安装的网页。要说明的是，它在第一轮查看文件夹时，顺手读到了我们藏 Python 用的设置文件，也就是说从那以后它是知道 Python 被藏起来了、实际放在哪的。它之后没有去用。它是先查的环境、后读到的设置。这只是模拟：真正什么都没装的电脑和这台还是会有差别。
- **手机上没有全试过。** 最终版在真手机上看过，排版没问题。选文件、打包下载这条路是在电脑上模拟的手机屏里核的；**微信里打开、苹果手机上都没试。**
- 汇总表没有专门在 Excel 和 WPS 里核过（录制的电脑上没装这两个）。

每一版是怎么核对的、结果是什么，见 [`核对/核对结果.md`](核对/核对结果.md)。

## 课后作业：已知的毛病，留给你练手

下面这些我们核对时发现了，故意没让它改。你可以把 `发票整理助手.html` 放进一个文件夹，用 Claude 桌面版的 Code 选中这个文件夹，像课上那样用大白话说，看它怎么改。改之前先把文件复制一份留底。

**1. 销售方名字里有空格，只认到第一段。** 比如 `ABC Trading (Shanghai) Co., Ltd.` 只认出 `ABC`，而且状态还是「正常」。

> 你可以这样问它：销售方的名字里有空格的时候，你只认到了第一个空格前面，比如英文公司名。帮我改成能认全。改完用样例发票再跑一遍，别把原来对的弄错了。

**2. 销售方名字太长、在发票上折成两行的，只认到前半截，也不提醒。**

> 你可以这样问它：有的发票销售方名字太长，折成了两行，现在只认到第一行，还显示「正常」。能不能把两行接起来？拿不准的时候，至少标出来让我自己看一眼。

**3. 没有销售方的票（火车票那一类）会被放进「需要人工检查」。**

> 你可以这样问它：火车票上没有销售方这一栏，现在都进了「需要人工检查」。帮我想个办法让它也能自动归到交通出行里。

**4. OFD 格式的发票和拍的照片都读不了；OFD 的提示还说它是「图片或扫描件」，这句不准。**

> 你可以这样问它：OFD 格式的发票现在读不了，提示却说它是图片或扫描件。先把这句提示改准确。再告诉我，要让它能读 OFD 得怎么做，难不难。

**5. 免税的发票，表格里「金额(不含税)」和「税额」两格是空的。**

> 你可以这样问它：免税的发票，汇总表里不含税金额和税额是空的。帮我把这两格填上，并在备注里写明是免税。

还有两处小的：

- 选了「它们不是重复，都保留」的那两张，汇总表里看不出是你手动保留的。可以问它：帮我在备注里注明这两张号码相同、是我选择都保留的。
- 手机上看发票原件，字太小。可以问它：手机上看原件太小了，能不能放大。

改完怎么知道它没改坏？让它「用样例发票再跑一遍」，或者自己用 `核对/` 里的脚本核。
